# Episode 0010 — imps goes fair-code (2026-08-08)

An impire-wide licensing decision lands here too: imps moves from MIT
to the **Sustainable Use License** (n8n's fair-code license, v1.0).
Use, modify, and self-host freely for internal or non-commercial
purposes; offering imps to others as a paid product or service now
requires an agreement. Public explanation:
[impire.io/license](https://impire.io/license/).

- `LICENSE` replaced with SUL v1.0 (provenance preamble kept); both
  README license mentions rewritten.
- No releases have been tagged, so no MIT-era versions exist to carve
  out; the new terms apply from the first tag.
- Sole authorship verified (`git shortlog -sne`: one author, two email
  identities) before the change.

Reversal condition: ecosystem-wide — see soul-hq journey 0064; if
fair-code suppresses the adoption the framework exists for, MIT
returns.
